# Проверка AdamLife 2.0 / этап 2.1

Дата: 22 октября 2026. Окружение: Windows, Node.js 24.21, Vite 6.4.5, встроенный Chromium-браузер Codex. Физический iPhone и Safari/WebKit в этом окружении не тестировались.

## Автоматические проверки

- TypeScript: `npm run typecheck` — без ошибок.
- Vitest: **57 тестов, 5 файлов** — все проходят.
- Production: `npm run build` — успешно. Vite создаёт статический `dist/`, включая manifest, иконки и локальные шрифты.
- Готовый `dist/` дополнительно запущен через Vite preview: проверены четыре раздела, смена счёта/периода, отсутствие дублирования диаграмм и пустая консоль предупреждений/ошибок. Manifest и три PNG отдаются с HTTP 200 и правильным MIME. Временный production-preview после проверки остановлен; пользовательские dev/LAN-ссылки оставлены работающими.
- Сохранены исходные проверки финансов и localStorage. Устаревшие проверки трёх временных тем заменены проверками единственного Graphite; контраст основных текстов проверяется не ниже 4.5:1 на основных поверхностях. Это не полная сертификация WCAG.
- Дополнительно: аддитивная миграция, сумма начальных остатков, независимость общего остатка от переводов, фильтры и сортировки, календарные даты, дневные/накопительные суммы, среднее по календарным дням, нулевая база сравнения, повторение платежей через февраль и независимая оплата месяца, результат импорта и повторные ID, восстановление расширенного хранилища, PWA/PNG-размеры, уникальные ключи графиков.

- Обнаружено и исправлено дублирование круговой диаграммы при смене фильтров: соседние графики имели одинаковые React keys. После исправления многократно переключены все четыре варианта счетов и периоды — на экране всегда одна круговая и одна линейная диаграмма.

## Адаптивность и доступность

Проверены все четыре раздела на **360, 375, 390, 430, 768, 1440 px**. Горизонтального скролла документа/основной области и переполнения сумм не обнаружено. Горизонтально прокручивается только ограниченная полоса категорий. Мобильная навигация содержит ровно четыре раздела.

Повторена матрица при **125% корневого шрифта** (20 вместо 16 px). Временное QA-правило после проверки удалено. Размеры типографики переведены в rem; увеличение не вызывает горизонтального скролла/обрезки сумм. Это эмуляция увеличенного текста, не проверка системного Dynamic Type iOS.

Форма проверена при ширине 360 px и высотах 780/400 px с увеличенным текстом: содержимое прокручивается, действия остаются внизу диалога. Высота 400 моделирует уменьшение видимой области, но не заменяет настоящую экранную клавиатуру Safari. Для реального устройства остаётся проверить клавиатуру, safe-area, системное увеличение текста и standalone.

## Запуск и PWA

- Просмотр на компьютере: http://127.0.0.1:5173/.
- Дополнительный локальный LAN-сервер: http://192.168.0.184:5174/; HTTP 200 проверен с компьютера. Доступ с телефона зависит от общей Wi-Fi сети и правил Windows. Настройки брандмауэра не изменялись.
- Manifest: имя AdamLife, standalone, scope/start URL `/`, Graphite background/theme, PNG 192/512 и Apple icon 180; размеры файлов проверены тестом.
- Готовность manifest **не означает подтверждённую установку**. Нужна отдельная HTTPS-публикация и проверка физического iPhone. Service worker, offline-гарантия и синхронизация отсутствуют.

Скриншоты находятся в родительской папке `outputs/adamlife-2.1-preview/`. Все данные остаются тестовыми и локальными; backend, PostgreSQL, PDF-парсер и ИИ API не подключались. Этап завершается ожиданием визуального утверждения.
